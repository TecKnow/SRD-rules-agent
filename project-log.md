# Project log

## Finding data

### Source of truth

The source of truth for this project is the Dungeons and Dragons 5.5
Edition (D&D 5.5 or just D&D in this context) System Reference Document
(SRD). Dungeons and Dragons itself is proprietary. The D&D SRD is a
subset of the game released under a more permissive license and forms the basis
of the
independent third-party publishing ecosystem. The SRD contains the game's
mechanics, plus a foundational set of other elements like classes, spells,
and items. Elements are sometimes renamed or omitted to protect
intellectual property, and only the generalized names used in the SRD are
covered under the permissive license.

Previous versions of the SRD were licensed under the Open Gaming License
(OGL). Wizards of the Coast tried to create a new version of that license
that would "de-authorize" the original version. This, along with updated
terms that were radically different and widely perceived as onerous, lead
to a backlash. In response, eventually, the SRD was released under
Creative Commons Attribution 4.0 International (CC BY 4.0).

The latest version of the SRD is easily available. It has been included in
this project folder:

[D&D SRD 5.2.1](Resources/srd_cc_v5_2_1.pdf)

Unfortunately, it is only officially published in the form of a multi-column
PDF. PDFs are notoriously challenging to work with in code. I need to look
for a more machine-readable version.

## Developing a test set
### Conclusions up front
I found a test set on Huggingface [dnd5e-srd-qa](https://huggingface.co/datasets/datapizza-ai-lab/dnd5e-srd-qa)
specifically designed to test RAG systems.  I also used Claude 
and ChatGPT to create a test set of about 100 questions.  I'll be starting 
with the Huggingface question set and fall back on the additional questions 
generated by Claude if I need more detail. 

### Potential sources
If I want to develop a RAG-assisted AI agent to help resolve D&D 5.5E rules
questions, then I should try to demonstrate that such a thing is useful.  
Specifically, it should be more useful than simply asking a readily available
AI agent directly.

There are plenty of reasons to think that this might be the case. The 5.5E
rules are very new, and 5E has a much slower pace of new releases compared
to second and third edition D&D. There are also related-but-different
products like Pathfinder, and tremendous volumes of articles and forum
posts about them. Any widely trained foundational LLM might struggle to
stay specific to the current edition. Indeed, anecdotal evidence suggests
this is the case.

It should be relatively easy to develop a list of common questions and
well-sourced answers. There's a feature
called [Sage Advice](https://www.dndbeyond.com/sources/dnd/sae) that
gathers errata and has the game developers answer common rules questions.  
There are plenty of guides explaining the differences between fifth edition D&D
and 5.5E that could form the basis for questions.

Creating this test set manually would not be a good use of time, however, 
and I have no desire to expose myself to the depths of internet forums 
where the most complex questions are argued about.

### A curated question set
After the work described above, I was reviewing the generated reports on 
finding machine-readable data and noticed that one of them linked to a 
huggingface dataset.  That dataset turned out to be a set of questions and 
reference answers designed to test RAG systems on the SRD 5.2.1.  It is 
linked in my conclusions section above.
